# javascript BOM and DOM

This repository contains simple examples demonstrating the **Browser Object Model (BOM)** and **Document Object Model (DOM)** in JavaScript.  
It’s designed as a learning resource for beginners to understand how JavaScript interacts with the browser and webpage structure.

---

## 📂 Files Included
- **BOM.html** → Demonstrates BOM features such as alerts, confirm/prompt dialogs, location, history, navigator, and screen properties.
- **DOM.html** → Demonstrates DOM manipulation including text changes, style updates, adding/removing elements, and toggling classes.
- **README.md** → Documentation for the project.
